Herosaver 2

Exporta o personagem aberto no editor do Hero Forge como OBJ com cores e texturas ou STL, com a mesma pose, proporções e pintura da tela. Versão {{VERSION}}.

Instalar (Chrome, Edge ou Brave)

  1. Mostre a barra de favoritos: Ctrl + Shift + B (no Mac, ⌘ + Shift + B).
  2. Arraste este botão até a barra de favoritos:
    ⬇ Herosaver

    Esse favorito sempre baixa a versão mais recente do script deste site. Se você usa a sincronização da conta do navegador, ele aparece sozinho nos seus outros computadores.

    Esta página foi aberta de um arquivo local, então o favorito acima não teria de onde baixar o script. Publique a pasta no GitHub Pages (veja o README) ou use a versão offline abaixo.

  3. Abra heroforge.com, espere o personagem carregar e clique no favorito Herosaver. Um painel abre no canto da tela: escolha OBJ ou STL e as opções, depois clique em Exportar. Clique de novo no favorito ou aperte Esc para fechar o painel.

Se arrastar não funcionar: copie o código, aperte Ctrl + Shift + O (gerenciador de favoritos) → ⋮ → Adicionar novo favorito, coloque o nome "Herosaver" e cole o código no campo URL.

Versão offline (sem internet)

O mesmo script inteiro guardado dentro do favorito (cerca de {{INLINE_KB}} KB). Funciona sem depender deste site, mas não se atualiza: quando sair versão nova, arraste de novo.

⬇ Herosaver (offline)

O que sai

  • OBJ num .zip: .obj com normais, UVs e cor por vértice, .mtl com materiais PBR e uma pasta textures/ (cor com decalques, rugosidade, metal, normal map e emissão).
  • STL binário, pronto para o fatiador.
  • Escala em milímetros (a base padrão mede 25 mm). No Blender: File → Import → Wavefront (.obj), nas configurações padrão.
